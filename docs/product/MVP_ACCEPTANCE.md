# MVP Acceptance Criteria

A commercial MVP is **not claimed** until this checklist passes as an automated end-to-end acceptance test through UI and API.

## Required journey (AI-operated customer refund)

- [ ] Organization created
- [ ] Authenticated team member
- [ ] Refund agent registered
- [ ] Payment simulator adapter registered
- [ ] Signed organization policy activated
- [ ] Exact refund effect proposed
- [ ] Risk assessment displayed
- [ ] Human approval requested
- [ ] Required quorum completed
- [ ] Effect committed exactly once through the simulator
- [ ] Independent ledger observation
- [ ] Signed Action Passport generated
- [ ] Audit trail searchable
- [ ] Modified amount or recipient rejected
- [ ] Duplicate retry prevented
- [ ] Ambiguous timeout recovered honestly
- [ ] Compensation handled as a separate authorized effect
- [ ] Cross-tenant access rejected
- [ ] Offline passport and audit verification successful

## Status

**Not yet MVP.** All 25 protocol-foundation phases and the commercial
Gateway, typed sync/async SDK, and real Control Center refund journey are
implemented. The dedicated buyer-facing end-to-end acceptance command,
Docker Compose evaluation path, and real Control Center screenshots/demo
recording are still required before this checklist may be checked off.
