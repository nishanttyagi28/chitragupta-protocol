# Open Core Boundary

## Open (protocol / Core)

- EffectManifest, seals, grants, delegation
- Lifecycle engine and audit journal
- Reference adapters (sqlite, email sandbox, payment simulator)
- CLI, library API, Action / Compensation Passports
- Extreme-v2 protocol phases as they land

## Commercial / closed evaluation surfaces (planned)

- Multi-tenant Control Center UX
- Hosted Gateway with org billing hooks
- Enterprise signer / SSO / retention packages
- Buyer evaluation bundles and support tooling

## Rule

Protocol security invariants remain open and inspectable. Commercial packaging must not weaken fail-closed behavior or invent provider guarantees the open core does not implement.
