# Product Roadmap

## Milestone A — Sellable evaluation experience

- Commercial architecture docs
- Durable organization model
- Refund vertical slice (API + UI)
- Typed async Python SDK
- Ten-minute quickstart
- Gateway HTTP API + Control Center approval inbox
- Before/after effect view, timeline, passport viewer, audit search
- Docker Compose evaluation
- Migrations + automated commercial acceptance test
- Deterministic demo + README assets from the real app

## Milestone B — Team deployment

- Server-enforced RBAC, approval groups, signed policies
- Webhooks with replay protection
- Durable workers, multi-tenant isolation
- Usage metering, operator docs, backup/restore/upgrade guidance

## Milestone C — Enterprise evaluation

- External signer + SSO interfaces
- Advanced approval groups, multi-witness
- Retention, support bundles, production architecture guidance
- Security questionnaire draft, buyer evaluation package, benchmarks
